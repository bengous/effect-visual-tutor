# Claude Design Output Contract

Claude Design should produce a design handoff that the implementation agent can apply without redesigning the product.

## Required Sections

1. Visual direction
2. Design principles
3. Semantic color system
4. Typography system
5. Layout grammar
6. Component patterns
7. Progressive disclosure rules
8. Diagram language
9. Motion spec
10. Accessibility and reduced-motion rules
11. Specimen screens
12. Engineering handoff notes

## Binding Rules

- First screen is the learning experience, not a landing page.
- Code remains the primary object of attention.
- UI copy is French.
- Source identifiers remain English.
- Animations explain conceptual transitions.
- Motion is not decorative.
- Simple view precedes detail view.
- The design must support split view: code plus concept diagram.
- The design must support guided mode and free exploration.
- The design must support reduced motion.

## Adaptable Details

The implementation agent may adjust small layout details for responsiveness, text fit, and accessibility.

Any substantial deviation from the validated design direction, semantic colors, component model, or motion language requires explicit user approval.
